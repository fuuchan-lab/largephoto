# LargePhoto

スクロールした画面（地図アプリなど）をつなげて、**1枚の大きな四角形の画像**として保存するウェブアプリです。
ビルド不要の静的サイトで、画像はすべて端末内で処理されます（送信しません）。

## 取り込み方法

| 方法 | 対応 | 使い方 |
| --- | --- | --- |
| スクリーンショット | すべて | 前の画面と3割ほど重なるようにスクロールしながらスクショ → ［＋画像］でまとめて選択 |
| 画面収録（動画） | すべて（iPhone/Android 推奨） | 画面収録しながら地図を縦横にゆっくりスクロール → ［▶動画］で選択 |
| ライブ取り込み | PC の Chrome / Edge など | ［◉ライブ］→ Googleマップ等のタブ/ウィンドウを共有してスクロール。取り込み範囲がリアルタイムに表示され、［別窓ミニマップ］で常に手前に表示可能 |

- **赤い斜線** = まだ埋まっていない範囲。全体（外接する四角形）のどこが欠けているか一目でわかります。
- 位置が分からなかった画像は赤い点線で右側に置かれます。［✥調整］でおおよその位置へ指でドラッグすると自動で吸着します。
- ［⬇保存］で PNG / JPEG に書き出し。端末の上限（iPhone は約1,670万画素）を超える場合は自動で縮小を提案します。

> ブラウザの制約で、スマホのウェブアプリから他のアプリの画面を直接リアルタイムに読み取ることはできません。スマホでは「画面収録 → 動画読み込み」が最も手軽です。

## 仕組み

- 画面上下の検索バーなど**動かない部分を切り抜き**で除外
- 位相限定相関（FFT）で移動量の候補を探し、正規化相互相関で検証 → 1/4 解像度 → フル解像度で 1px 単位に詰める（`js/register.js`）
- 動画/ライブは連続フレームを追跡し、未取得部分が一定以上になったフレームだけをタイルとして追加。見失ったら既存タイルと照合して復帰（`js/stitcher.js`）
- 平行移動のみ対応（途中で拡大縮小・回転しないでください）

## 開発

```sh
npm start            # http://localhost:8000 で起動（任意の静的サーバーで可）
npm test             # 位置合わせの単体テスト（Node）
npm run test:e2e     # Playwright での通し試験（スクショ・動画・書き出し）
```

GitHub Pages などにそのまま置けば公開できます（スマホのカメラロール保存・PWA 化には HTTPS が必要）。
